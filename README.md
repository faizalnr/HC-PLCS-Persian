# HC-PLCS-Persian-
This code is part of our new project titled "HC-PLCS: A Hierarchical Context-Aware Persian Linguistic Cryptographic Standard for Secure and Human-Readable Communication" which is ongoing review process in reputed journal.
Python implementation of HC-PLCS:
Run **_HC_PLCS_single_text_execution.py_** using any python editor for single-text processinga nd evaluation. 
Run **_HC_PLCS_Dataset_text_execution.py_** using any python editor for Dataset processinga nd evaluation. 
Datset file (input and generated controlled Dataset is **_Dataset.xlsx_** and the public Dataset is **_train.csv_**
